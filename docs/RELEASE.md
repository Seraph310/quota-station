## English

Quota Station now speaks English and Chinese, with a new bilingual project homepage and public demo gallery.

- Right-click the card or tray icon → **Language / 语言** → **System default / 简体中文 / English**. Switching is immediate and remembered after restart.
- Translates the card, expanded quotas, sources, sync details, tray menu, update window, accessibility descriptions and connection errors. Existing cached readings are translated for display without changing account identities, balances or selections.
- English and Chinese README pages, download guides, screenshots and issue templates make it easier to get started and share the project.
- Adds **PolyForm Noncommercial License 1.0.0**. Commercial uses outside its permitted purposes require separate authorization; third-party components retain their own licenses. License files are included in every package.
- Keeps Magpie sync, animated page turns, edge quota bars and in-app updates.

| System | Package |
| --- | --- |
| Windows 10/11 x64 | `windows-x64.zip` — extract fully, open `QuotaStation/QuotaStation.exe` |
| macOS · Apple silicon | `macos-arm64.dmg` — drag the app into Applications |
| macOS · Intel | `macos-x64.dmg` — drag the app into Applications |

Python is not required. v0.4.0 users can update from inside the app. Windows supports Codex, Qoder, WorkBuddy and Magpie; macOS supports Codex CLI and Magpie. Both Mac builds are tested on macOS 15. Packages remain unsigned on Windows and ad-hoc signed without notarization on macOS; see the [download guide](https://github.com/Seraph310/quota-station/blob/main/docs/DOWNLOAD.en.md).

All platforms run offline tests, render both languages from the packaged app, and perform an isolated real upgrade with settings preservation and startup verification. Public assets contain synthetic data only. Physical Mac sign-in flows for every upstream provider have not been individually verified.

## 简体中文

小站现在支持中英文界面，并新增适合社区分享的双语项目首页和演示图。

- 右键卡片或托盘 → **Language / 语言** → **跟随系统 / 简体中文 / English**，即时切换、重启保留。
- 卡片、展开列表、来源选择、同步详情、托盘菜单、更新窗口、无障碍提示和连接错误均支持翻译。原有缓存仅在显示时翻译，账号、额度和选择不改变。
- 新增中英文 README、下载说明、演示截图和问题反馈模板。
- 采用 **PolyForm Noncommercial License 1.0.0**，超出许可允许范围的商业用途需另行授权；第三方组件保留各自许可。所有安装包附带许可证。
- 保留 Magpie 同步、双向翻页、侧边额度条与应用内更新。

无需 Python。v0.4.0 可直接在小站里检查更新并升级。Windows 支持 Codex、Qoder、WorkBuddy、Magpie；macOS 支持 Codex CLI 与 Magpie。Mac 包在 macOS 15 上构建和验证。首次启动说明见[下载版指南](https://github.com/Seraph310/quota-station/blob/main/docs/DOWNLOAD.md)。

三平台均执行离线测试、打包程序双语界面检查，以及真实替换、保留设置和启动新版的隔离升级验证。公开素材只用虚构数据，尚未逐一验证实体 Mac 上每个平台的真实账号登录。
